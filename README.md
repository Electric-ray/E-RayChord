# ErayChord 사용법 (메인 반주 생성기)

## 이게 뭐 하는 플러그인인가요

악보에 이미 입력된 코드(Symbol)를 읽어서, 내가 고른 리듬 패턴 + 코드
운지로 기타 반주를 자동 생성합니다. "자동 작곡"이 아니라 **"패턴 기반
자동 반주 생성"** 도구입니다 — 코드 진행은 사용자가 이미 만들어 둔
것을 그대로 씁니다.

---

## 설치

1. `ErayChord` 폴더 전체를 MuseScore Plugins 폴더에 복사합니다.
   - Windows: `문서\MuseScore4\Plugins\`
   - macOS: `~/Documents/MuseScore4/Plugins/`
2. MuseScore를 실행하고 **Plugins > Manage Plugins...**에서 "ErayChord"를
   찾아 활성화합니다.
3. **Plugins > ErayChord** 메뉴가 나타나면 준비 완료입니다.

---

## 사용 전 준비물

- 반주를 만들 마디에 **코드(Symbol)가 이미 입력**되어 있어야 합니다
  (예: `C`, `Am`, `Dm`, `G7`).
- 반주를 기록할 트랙(보통 Guitar 트랙)이 **미리 존재**해야 합니다.
  (이 플러그인은 새 트랙을 자동으로 만들지 않습니다.)

---

## 화면 구성

| 항목 | 설명 |
| --- | --- |
| 카테고리 / 패턴(주법) | 리듬 패턴 선택. 카테고리를 먼저 고르면 그 안의 패턴만 목록에 나온다 |
| 미리보기 | 선택한 패턴의 리듬 그림 — 위 칸 = 코드, 아래 칸 = 베이스, X = 뮤트, 주황색 = 액센트 |
| 운지 이름 우선순위 | 비워두면 기본(default) 운지 사용. "오픈", "바레(E폼)", "바레(A폼)" 등을 입력하면 그 이름의 운지를 우선 사용(없으면 자동으로 기본 운지로 대체) |
| [읽기 + 미리보기] | 선택한 마디의 코드를 읽고, 실제로 생성될 음표 이벤트를 미리 보여줌 (아직 악보에는 안 씀) |
| [악보에 쓰기] | 미리보기에서 확인한 내용을 실제로 악보에 기록 |
| [라이브러리 새로고침] | Pattern Editor / Voicing Editor에서 새로 저장한 패턴·운지를 다시 불러옴 |
| 결과 텍스트 창 | 코드 진행, 생성된 이벤트 목록, 오류/건너뜀 내역 등을 보여줌 |
| [전체 복사] / [닫기] | 결과 텍스트 복사 / 창 닫기 |

---

## 사용 순서

1. MuseScore에서 **반주를 넣고 싶은 트랙**의, **코드가 붙은 마디들**을
   선택합니다.
2. **Plugins > ErayChord**를 실행합니다.
3. 카테고리 → 패턴을 고릅니다. 미리보기로 리듬 모양을 확인합니다.
4. (선택) 운지 이름 우선순위를 입력합니다. 예를 들어 하이코드로 치고
   싶으면 "바레(E폼)" 또는 "바레(A폼)"을 입력합니다. 비워두면 자동으로
   각 코드의 기본 운지가 쓰입니다.
5. **[읽기 + 미리보기]**를 클릭합니다. 결과 창에서 코드 진행과 생성될
   음표 목록을 확인합니다.
6. 이상 없어 보이면 **[악보에 쓰기]**를 클릭합니다.
7. 결과를 확인합니다. 마음에 안 들면 **Ctrl+Z**로 되돌리고, 패턴이나
   운지를 바꿔서 다시 시도합니다.

---

## 알아두면 좋은 것들

- 운지 라이브러리에 없는 코드는 자동으로 3화음(triad)으로 대체됩니다.
- 새 패턴이나 새 코드 운지를 추가하고 싶으면 **Pattern Editor** /
  **Voicing Editor**를 사용한 뒤, 여기로 돌아와 **[라이브러리 새로고침]**을
  누르면 바로 반영됩니다.
- 기본 제공 라이브러리
  - 리듬 패턴: 13개 카테고리(고고 / 슬로우고고 / 셔플 / 칼립소 /
    보사노바 / 컨트리 / 폴카 / 트로트 / 룸바 / 비긴 / 발라드 /
    슬로우락 / 포크), 총 37개
  - 코드 운지: 12개 키 × 메이저/마이너/7th/m7/sus4/dim7, 72개 코드에
    127개 운지(오픈 + 바레/하이코드)

---

## 한계 (알고 있는 것)

- **4/4 박자만** 정확히 지원합니다. 다른 박자표의 곡에 쓰면 마디 길이
  계산이 어긋나 결과가 부정확할 수 있습니다.
- 코드 구성음을 한 음씩 순서대로 뜯는 **진짜 아르페지오**는 아직
  지원하지 않습니다. 각 슬롯은 "화음 전체" 또는 "단음(베이스)"만
  표현할 수 있습니다.
- 셔플, 보사노바, 룸바, 비긴처럼 스윙이나 당김음이 강한 장르는
  셋잇단음표·타이를 못 쓰기 때문에 **스트레이트 8분음표 근사치**로
  들어 있습니다.
- 새 Guitar 트랙을 자동으로 만들어주지는 않습니다. 미리 트랙을
  만들어 두고 그 트랙을 선택한 상태에서 실행하세요.
